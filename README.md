## Configure Claude Code with your provider

### Claude Code Edit the configuration

Paste the following configuration block into the file. Replace `your_agent_router_api_key` with the API key you generated on the provider Token Console:

```json
{
  "autoUpdatesChannel": "latest",
  "theme": "light",
  "model": "opus",
  "env": {
    "ANTHROPIC_BASE_URL": "https://yourprovider.org",
    "ANTHROPIC_AUTH_TOKEN": "your_router_api_key",
    "ANTHROPIC_API_KEY": "",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-8",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-opus-4-8",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-opus-4-8",
    "CLAUDE_CODE_SUBAGENT_MODEL": "claude-opus-4-8"
  }
}
```

## Before you use an AI API gateway

- **Verify model identity.** A listed model name does not guarantee that every request is served by the original provider or an identical model version. Run your own test prompts before using a gateway in production.
- **Protect sensitive data.** Read each service’s privacy policy, retention terms, and acceptable-use rules before sending source code, personal data, credentials, or regulated information.
- **Confirm the cost.** Signup credits and daily check-in rewards are promotional and may have expiry dates, spending caps, or eligibility requirements.
- **Check API compatibility.** Confirm whether the provider supports the OpenAI, Anthropic, Gemini, or another API format required by your application.
